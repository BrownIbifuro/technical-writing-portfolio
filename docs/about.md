## Documentation Philosophy

My approach to documentation is guided by three principles:

1. **Clarity:** Information should be easy to understand and navigate.
2. **Accuracy:** Technical explanations should reflect actual system behaviour and verified information.
3. **Usability:** Documentation should help readers complete tasks, solve problems, and use software confidently.
