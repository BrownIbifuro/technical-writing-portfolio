## Documentation Philosophy

My approach to documentation is guided by three principles:

1. **Clarity:** Information should be easy to understand.
2. **Accuracy:** Technical explanations should reflect actual system behaviour.
3. **Usability:** Documentation should help readers accomplish specific tasks.
